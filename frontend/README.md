# Frontend

This folder contains the InternAtlas Next.js frontend:

- `src/app` — pages/routes
- `src/components` — UI components
- `src/data` — frontend/static data
- `src/lib` — frontend helpers
- `public` — static assets

`src/app/api` contains only thin Next.js route adapters. Backend logic and D1 access are in `../backend/src`.
